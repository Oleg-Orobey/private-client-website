# Private Client Website

Веб-сайт, разработанный по индивидуальным требованиям заказчика.

Проект разработан на PHP с использованием MySQL/MariaDB и включает публичную часть сайта, регистрацию пользователей, личный кабинет, обработку заявок, отзывы и административную панель.

Возможности
главная страница с описанием услуг;
регистрация и авторизация пользователей;
личный кабинет;
отправка заявок на ремонт;
обработка заявок в административной панели;
управление статусами заявок;
добавление и удаление фотографий выполненных работ;
система отзывов и оценок;
разграничение прав пользователей и администратора;
загрузка изображений с серверной валидацией.
Технологии
PHP 8.1+
MySQL / MariaDB
HTML5
CSS3
JavaScript
PDO
Apache / .htaccess
Безопасность

В проекте реализованы базовые меры защиты веб-приложения:

хранение паролей через password_hash;
проверка CSRF-токенов для POST-действий;
подготовленные SQL-запросы;
серверная валидация пользовательских данных;
экранирование выводимых пользовательских данных;
ограничение частоты запросов;
строгие параметры сессий и регенерация идентификатора после входа;
базовые security headers;
проверка прав администратора;
honeypot для формы заявки;
ограничение размера загружаемых изображений;
проверка MIME-типа и содержимого изображений;
случайные имена загружаемых файлов;
запрет выполнения скриптов в каталоге загрузок.

Структура проекта
public/     — публичная часть приложения
config/     — конфигурация подключения и настроек
sql/        — структура базы данных
storage/    — локальное хранилище приложения

Установка
Установить PHP 8.1+ и MySQL/MariaDB.
Настроить виртуальный хост так, чтобы web-корнем был каталог public/.
Создать базу данных на основе sql/schema.sql.
Создать локальный файл config/db.php на основе config/db.example.php.
Указать параметры подключения к базе данных.
Настроить config/site.php на основе config/site.example.php.
Убедиться, что каталог storage/ и public/uploads/ доступны приложению для записи.
В production использовать HTTPS.
Важная информация

Файлы с локальными настройками, паролями, пользовательскими загрузками и инструментами первоначальной установки не входят в публичный репозиторий.

Для production необходимо использовать отдельные учётные данные базы данных и не хранить их в исходном коде.
