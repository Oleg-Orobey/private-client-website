# Ремонт рядом

Веб-приложение для сайта ремонтной компании с каталогом работ, формой заявки, регистрацией пользователей и административной панелью.

## Возможности

- адаптивная главная страница;
- регистрация и авторизация пользователей;
- личный кабинет;
- отправка заявок на ремонт;
- административная панель для работы с заявками и работами;
- загрузка изображений с серверной валидацией;
- хранение данных в MySQL/MariaDB.

## Технологии

- PHP 8.1+;
- MySQL/MariaDB;
- HTML5;
- CSS3;
- JavaScript;
- PDO.

## Безопасность

В проекте реализованы:

- подготовленные SQL-запросы;
- хеширование паролей через `password_hash`;
- проверка паролей через `password_verify`;
- CSRF-защита форм;
- серверная валидация пользовательских данных;
- ограничение частоты запросов;
- проверка загружаемых файлов по MIME-типу и размеру;
- безопасные имена загружаемых файлов;
- базовые HTTP security headers;
- запрет выполнения PHP-файлов в каталоге загрузок.

## Структура

```text
config/                 конфигурация приложения без секретов
public/                 публичная часть сайта
public/partials/        общая PHP-логика приложения
public/uploads/         каталог пользовательских загрузок
sql/                    структура базы данных
```

## Локальный запуск

1. Установите PHP 8.1+ с расширениями PDO MySQL и Fileinfo.
2. Настройте переменные окружения `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASS`.
3. Создайте базу данных и выполните `sql/schema.sql`.
4. Настройте веб-сервер так, чтобы его document root указывал на `public/`.
5. Для production используйте отдельного пользователя БД с минимально необходимыми правами и HTTPS.

## Публичный репозиторий

В репозитории не хранятся пароли БД, локальные установочные файлы, диагностические скрипты и реальные пользовательские загрузки.
